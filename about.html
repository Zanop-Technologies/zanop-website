About Zanop Technologies

Zanop Technologies was founded in 2022 by John Adman. What started as a fictional, for-fun Operating System project eventually became real — and that real project is what you're reading about now.

Before Zanop Technologies had a GitHub organization, Zanop OS existed only as an idea, complete with fictional products dreamed up for it, such as the Zanop A Series smartphone, deeply inspired by the Samsung A Series.

The Zanop Kernel

At the heart of everything Zanop builds is the Zanop Kernel, written from scratch in Rust with select low-level portions in Assembly, targeting the x86_64 architecture. Rather than being tied to a single product, the kernel is designed to power multiple Zanop OS variants:

Variant Purpose
Zanop Desktop OS Desktop environment, uses .sft as its app file format
Zanop Mobile OS Mobile-focused variant
Zanop Television OS Television/set-top variant

Our Philosophy

We believe an operating system should be built with care, from the ground up — not assembled from someone else's parts. Zanop OS is not a Linux distribution; it runs on its own kernel, built line by line by people who simply wanted to see if they could build one.
